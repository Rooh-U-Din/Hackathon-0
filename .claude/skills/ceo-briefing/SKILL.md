# CEO Briefing Generator Agent Skill

## Overview

The CEO Briefing Generator is a Gold Tier Agent Skill that autonomously analyzes your business performance and generates executive briefings. It transforms your AI Employee from reactive to proactive by providing weekly insights, identifying bottlenecks, and suggesting cost optimizations.

## Features

- **Revenue Analysis**: Tracks weekly and monthly revenue against targets
- **Task Analysis**: Reviews completed tasks and identifies bottlenecks
- **Cost Optimization**: Identifies unused or expensive subscriptions
- **Proactive Suggestions**: Recommends actions based on data patterns
- **Deadline Tracking**: Monitors upcoming project deadlines
- **Automated Reporting**: Generates professional markdown briefings

## Installation

No additional dependencies required. Uses Python standard library.

## Usage

### Basic Usage

```bash
# Generate weekly briefing
python .claude/skills/ceo-briefing/skill.py

# Custom vault location
python .claude/skills/ceo-briefing/skill.py --vault /path/to/vault

# Analyze last 14 days
python .claude/skills/ceo-briefing/skill.py --period-days 14
```

### Scheduled Usage

Add to your scheduler for automatic Monday morning briefings:

```python
# In scheduler.py
def generate_ceo_briefing():
    """Generate CEO briefing every Monday at 7 AM."""
    return run_skill("ceo-briefing", "--period-days 7")

schedule.every().monday.at("07:00").do(generate_ceo_briefing)
```

## Required Vault Structure

The skill expects the following structure:

```
AI_Employee_Vault/
├── Business_Goals.md          # Revenue targets and metrics
├── Done/                      # Completed tasks
├── Logs/                      # Transaction logs
│   └── *_transactions.json
└── Briefings/                 # Generated briefings (auto-created)
    └── YYYY-MM-DD_Monday_Briefing.md
```

## Business_Goals.md Template

Create this file in your vault root:

```markdown
---
last_updated: 2026-02-27
review_frequency: weekly
---

## Q1 2026 Objectives

### Revenue Target
- Monthly goal: $10,000
- Current MTD: $4,500

### Key Metrics to Track
| Metric | Target | Alert Threshold |
|--------|--------|-----------------|
| Client response time | < 24 hours | > 48 hours |
| Invoice payment rate | > 90% | < 80% |
| Software costs | < $500/month | > $600/month |

### Active Projects
1. Project Alpha - Due Jan 15 - Budget $2,000
2. Project Beta - Due Jan 30 - Budget $3,500

### Subscription Audit Rules
Flag for review if:
- No login in 30 days
- Cost increased > 20%
- Duplicate functionality with another tool
```

## Troubleshooting

**No briefing generated**
- Verify vault path is correct
- Check that Business_Goals.md exists
- Ensure /Done and /Logs directories exist

**Revenue shows $0**
- Check transaction logs exist in /Logs
- Verify JSON format is correct
- Ensure transactions have type: "income"

**No tasks shown**
- Verify /Done folder has .md files
- Check file modification times are recent
