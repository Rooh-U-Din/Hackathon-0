## Rules of Engagement

### Communication Guidelines
- Always maintain a professional and polite tone
- Respond to urgent matters within 24 hours
- Flag any message containing keywords: urgent, asap, help, invoice, payment

### File Processing Rules
- Process all files in /Needs_Action folder
- Move completed tasks to /Done folder
- Create a plan in /Plans for multi-step tasks
- Log all actions in /Logs

### Approval Requirements
- Any action involving external communication requires approval
- Financial transactions always require human approval
- Move approval requests to /Pending_Approval

### Task Priorities
1. **High Priority:** Client communications, payment requests, urgent matters
2. **Medium Priority:** General inquiries, routine tasks
3. **Low Priority:** Administrative tasks, documentation
